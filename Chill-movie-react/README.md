# Chill — Movie Website

Website movie statis berbasis ReactJS, dibuat mengikuti case brief:
- Register
- Login
- Homepage
- Reusable components
- Responsive design
- Client-side validation
- Dummy authentication dengan localStorage
- Movie discovery UI

## Run

```bash
npm install
npm run dev
```

Build:

```bash
npm run build
```
